## 2. 课程的设计应该覆盖 R 语言的方方面面

`walkthroughs` 应当是可以配置多套向导课程貌似是数组。并且希望（向导课程支持l10n）

比如

1. 环境的的安装与配置 （能自动检测感知当前的环境状态）有升级提醒等支持
    1. `R Console` 与 `R`（https://cloud.r-project.org/bin/macosx/）,
    2. `languageserver` （这个是目前唯一的方案吗？我不太清楚）比如可能还有有 `languageserversetup` （有了 R 终端命令后就能通过 `R` 进入并可以通过可视化操作调用 install.package(`languageserver`)之类的操作，这也是此插件针对 R 语言的的一些代码补全，验证代码合规，lint 等常规操作所需要的基础设施。当让是否还需要全局安装其它的工具（我不清楚，也需要你系统科学的补全）
2. R 语言开发入门
    1. 认清楚 `R` 语言生态的文件格式的作用与用途（对 R 生态有一个基础概念）
    2. R 里的 package 的概念
    3. 语法知识（3，4，5，6，7）等覆盖 r 语言所有的语法规则。
    4. 常见问题与注意事项
3. Getting Started R with vs code （learn how to use the R extention for for VS code）
    1. 创建 R 项目
    2. 使用模版创建 （未来支持使用调度 copilot 聊天式对话进行调度与创建）
        1. Starter（基础模版）
        2. 金融分析
        3. 生物信息
        4. 市场调研
        5. 公共卫生
        6. 教育评估
        7. 添加自定义模版（.Rtemplate）
    3. R 语言包
    4. 认识 R 项目/包 目录结构（官方/社区规范）
    5. 测试与调试
    6. 打包分发
    7. 报告产出

> 总之希望整个课程分清楚阶段进行设计，并能让一个小白甚至非计算机专用用户零基础上手 R 语言学习，开发，产出高质量的有价值的东西。（所以你可以自行补充一个方案与文案编排给到我后确认总体方向后再进入编码开发。

## 3. 就是不仅仅对 `.R` 文件类型的语法高亮支持

- 不知道借助 环境安装的 `languageserver` 是否可以对齐到 插件 `REditorSupport.r-syntax` 所有的功能
- 对 R [生态整个文本类型文件](./R-DOMAIN.md#25-文件图标支持)都支持语法高亮与相关能力（避免文件有错误不合规），比如有的时候多了一个空格之类可能就会造成无法感知的错误
- r 语言的语法高亮，我希望变量，函数之类的一些概念都有属于自己的颜色，对齐 ts 的变量，函数之类的颜色设定，让人一眼看过去就能知道这个是什么。（毕竟人类是视觉处理信息的主要方式）
- 有了 `languageserver` 后会有 自动补齐代码的能力吗？比如 <- 这一类的符号最好还是能自动不齐之类。

> 补充：主要是围绕 r 生态的一些必须与火可选的的文件类型也支持语法高亮与补充，能对齐 package.json 之类的体验，能检查是否有非法字符等错误信息等。有hover 提示，名说明每个配置的用途和可选配置等。（总之体验上要超越`REditorSupport.r-syntax` 并有自己更高效的实现方式）
